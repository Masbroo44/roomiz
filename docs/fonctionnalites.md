# Fonctionnalités

| Écran                   | Ce qu'on y fait                                                    | API |
| ----------------------- | ------------------------------------------------------------------ | --- |
| Accueil                 | Logo, accroche, choix « je cherche » ou « j'ai une chambre »       | Non |
| Créer mon profil        | Prénom, âge, ville, budget, centres d'intérêt, bio                 | Oui |
| Connexion / Inscription | Se connecter ou créer un compte                                    | Oui |
| Vérifier mon identité   | Obtenir le badge Verified Key                                      | Oui |
| Explore                 | Cartes de logements : swipe sur le côté pour passer, bouton Toquer | Oui |
| Fiche annonce           | Détail d'un logement                                               | Oui |
| Mes critères            | Critères de recherche, dont She Space                              | Oui |
| My Room                 | Mon profil et mon annonce                                          | Oui |
| Knocks                  | Liste des Toquer                                                   | Oui |
| Porte ouverte !         | Écran de match                                                     | Non |
| Living Room             | Messagerie                                                         | Oui |
| Knock Knock             | Chat anonyme guidé                                                 | Oui |

Porte ouverte ! n'appelle pas l'API : l'écran affiche un match déjà chargé par
Knocks.

Les routes sont dans [api.md](api.md).
