# Choix techniques

- **Vite** : démarrage rapide, rechargement instantané, très peu de config.
- **React** (plutôt que Preact) : standard, gros écosystème, équipe à l'aise.
- **React Router v6** : toutes les routes au même endroit, dans `App.jsx`.
- **CSS Modules + variables CSS** : styles isolés par composant, charte
  centralisée dans `tokens.css`, aucune librairie d'UI.
- **vite-plugin-pwa** : app installable, manifest et service worker créés au
  build.
- **ESLint + Prettier** : erreurs repérées tôt, même mise en forme pour tous.
- **JavaScript** (pas TypeScript) : plus simple, rien de plus à apprendre.
