| ---------------------- | ------------------------ | ----------------------------- |
| `--color-primary`      | `#2F6BFF`                | Couleur principale            |
| `--color-primary-soft` | `#E8EFFF`                | Fond d'un élément sélectionné |
| `--color-secondary`    | `#00D1C1`                | Couleur secondaire            |
| `--color-accent`       | `#FFB800`                | Accent                        |
| `--color-bg`           | `#F5F8FF`                | Fond de l'app                 |
| `--color-text`         | `#0E1726`                | Texte                         |
| `--color-text-muted`   | `#5B6676`                | Texte secondaire              |

## Polices, rayons, espacements

- Titres : Bricolage Grotesque (`--font-title`).
- Texte : Inter (`--font-text`).
- Rayons : 12px (`--radius-sm`), 16px (`--radius-md`), 24px (`--radius-lg`).
- Espacements : multiples de 4px, de `--space-1` (4px) à `--space-12` (48px).

## Vocabulaire

- Toquer : liker.
- Porte ouverte ! : match.
- Knock Knock : match mystère.
- Vibe Check : score.
- Verified Key : badge identité.
- She Space : colocation 100 % femmes.
- Roomies : candidats.
- Onglets : Explore, Knocks, Living Room, My Room.

## Accessibilité

- Mobile-first : colonne de 430px max, centrée.
- Contraste : texte blanc sur `--gradient-action` seulement.
- Zones tactiles de 44px minimum.
- Champs de saisie en 16px minimum.
- Un label sur chaque champ.
- Focus visible au clavier.
